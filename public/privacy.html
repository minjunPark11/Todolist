FocusFlow 개인정보처리방침

최종 수정: 2026년 9월 5일

FocusFlow는 개인이 만들어 운영하는 할 일 관리 앱입니다. 이 문서는 앱이 어떤 데이터를 어디에 두는지, 그리고 무엇을 하지 않는지를 적은 것입니다.

1. 데이터는 먼저 기기에 있습니다

FocusFlow는 로컬 우선으로 동작합니다. 할 일, 목록, 캘린더, 집중 세션 기록은 앱을 쓰는 기기의 저장소에 먼저 기록되며, 로그인하지 않으면 그 기기를 떠나지 않습니다.

2. 로그인하면 계정에 동기화됩니다

계정으로 로그인하면 위 데이터가 Supabase에 있는 본인 계정의 행으로 동기화되어, 다른 기기에서도 같은 내용을 볼 수 있습니다. 각 행은 행 수준 보안(RLS)으로 본인 계정에만 열려 있습니다.

로그인에는 이메일 또는 구글 계정을 쓸 수 있습니다. 구글 계정으로 로그인하는 경우 FocusFlow가 받는 것은 계정 식별에 필요한 정보(이메일 주소 등)이며, 비밀번호는 받지도 저장하지도 않습니다.

3. 구글 캘린더 연동 (선택)

설정에서 직접 연결했을 때만 동작합니다. 연결하지 않으면 이 절의 내용은 전혀 일어나지 않습니다.

무엇이 오가는가

  • 연결 시 구글 계정에 "FocusFlow" 전용 캘린더를 하나 만들고, 그 캘린더만 읽고 씁니다. 회사 일정, 생일, 공휴일 등 다른 캘린더는 건드리지 않습니다.
  • 내보내는 것은 날짜가 지정된 할 일의 제목, 설명, 시작·종료 시각, 종일 여부, 반복 규칙뿐입니다.
  • 우선순위, 태그, 목록 구조, 체크리스트, 집중 세션 기록은 구글로 나가지 않습니다.

자격 증명을 어떻게 다루는가

  • 갱신 토큰(refresh token)은 서버에만 저장되며, 어떤 브라우저나 앱도 읽을 수 없는 테이블에 들어갑니다. 앱이 받는 것은 한 시간짜리 액세스 토큰뿐입니다.
  • 설정에서 연결 해제하면 저장된 토큰을 지우고 구글에 권한 회수를 요청합니다. 이미 캘린더에 들어간 일정과 캘린더 자체는 사용자의 것이므로 그대로 둡니다. 원하시면 구글 캘린더에서 직접 지우실 수 있습니다.

FocusFlow가 구글 API로부터 받은 정보의 사용과 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책을 따르며, 여기에는 제한적 사용(Limited Use) 요건이 포함됩니다. 구글 사용자 데이터는 위에 적은 캘린더 동기화 기능을 제공하기 위해서만 쓰이며, 광고에 쓰지 않고, 판매하지 않으며, 사람이 읽지 않습니다.

4. 데이터가 나가는 곳 전부

대상 언제 무엇
Supabase 로그인했을 때 할 일·목록·설정 등 앱 데이터, 계정 식별 정보
Google Calendar API 구글 캘린더를 연결했을 때 날짜가 있는 할 일의 일정 정보 (3절)
구독한 ICS 주소 외부 캘린더를 추가했을 때 사용자가 입력한 그 주소를 대신 받아오기 위한 요청 (브라우저 CORS 제약 때문)
GitHub Releases 데스크톱 앱이 업데이트를 확인할 때 버전 정보 요청. 앱 데이터는 보내지 않습니다
Google Fonts 웹에서 화면을 그릴 때 글꼴 파일 요청

이 표에 없는 곳으로는 아무것도 보내지 않습니다.

5. 하지 않는 것

  • 광고를 싣지 않습니다.
  • 분석·트래킹 도구를 넣지 않습니다.
  • 데이터를 제3자에게 판매하거나 제공하지 않습니다.
  • 할 일의 내용을 사람이 열어보지 않습니다.

6. 보관과 삭제

  • 삭제한 항목은 휴지통에 머물다가 완전 삭제 시 기기와 계정 양쪽에서 지워집니다.
  • 설정에서 언제든 전체 데이터를 JSON으로 내보낼 수 있습니다.
  • 설정의 전체 데이터 초기화로 앱 데이터를 지울 수 있습니다.
  • 계정 자체의 삭제나 남은 데이터의 삭제를 원하시면 아래 연락처로 요청해 주세요.

7. 어린이

FocusFlow는 어린이를 대상으로 하지 않으며, 어린이의 정보를 의도적으로 수집하지 않습니다.

8. 변경

이 방침이 바뀌면 이 페이지의 내용과 위의 최종 수정일이 함께 갱신됩니다.

FocusFlow Privacy Policy

Last updated: 5 September 2026

FocusFlow is a personal task app built and run by an individual. This is a plain summary of the Korean text above.

Where your data lives

FocusFlow is local-first: tasks, lists, calendars and focus sessions are written to the device you are using, and stay there unless you sign in. Signing in syncs them to rows in Supabase that only your own account can read.

Google Calendar (optional)

Only if you connect it in Settings. Connecting creates one dedicated "FocusFlow" calendar in your Google account, and that is the only calendar read or written. What leaves is the schedule slice of dated tasks — title, description, start and end, all-day flag and repeat rule. Priorities, tags, list structure, checklists and focus sessions never go to Google.

The refresh token is stored only on the server, in a table no browser can read; the app itself holds nothing but an access token good for one hour. Disconnecting deletes the stored token and asks Google to revoke the grant. Events already in your calendar, and the calendar itself, are yours and are left alone.

FocusFlow's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is used only to provide the calendar sync described above; it is never used for advertising, never sold, and not read by humans.

Everywhere data goes

Supabase (when signed in), the Google Calendar API (when connected), any ICS address you subscribe to — fetched through the app's own proxy because browsers block cross-origin calendar requests — GitHub Releases (the desktop app checking for updates; no app data is sent), and Google Fonts (font files). Nowhere else.

What FocusFlow does not do

No ads. No analytics or tracking. No selling or sharing your data. Nobody reads your tasks.

Keeping and deleting

Deleted items sit in the Trash before being removed from both the device and the account. You can export everything as JSON, or erase the app's data, from Settings at any time. For account deletion, write to the address below.

Children

FocusFlow is not directed at children and does not knowingly collect their information.
