# FocusFlow v0.22.16

반복 작업의 회차를 하나씩 편집할 수 있게 하고, Google 동기화를 승인이 필요한 작업에서
자동으로 도는 작업으로 바꿨습니다. 시간대는 일반 설정 한 곳에서 정해 앱과 Google 동기화에
함께 적용합니다.

- 반복 작업 수정·이동·삭제 시 이번 회차만 / 이번 회차 및 이후 / 전체 시리즈 선택
- 앱 반복 작업의 다음 회차가 캘린더 격자에 보이고, 완료한 회차는 자기 날짜를 기록
- Google 반복 일정의 회차 하나를 조건부 PATCH·DELETE 로 전송하고 회차 중복 생성을 차단
- 시간대를 검색해 고르거나 기기 시간대를 물려받도록 선택하고, Google 동기화 시간대를 제자리에서 재고정
- 겹치지 않은 필드 편집은 Google·기기 양쪽에서 자동 병합하고, 남은 충돌만 확인 필요로 표시
- 최근 30일의 변경 전 내용에서 복원, 취소된 미매핑 일정의 검토 자동 은퇴, 동기화 실패 사유를 화면에 그대로 표시
- 동기화할 캘린더 선택을 없애고 설정을 일반·알림·계정 및 동기화·연결·백업 및 복원·앱 정보로 재구성
- 아이젠하워 매트릭스에서 Delete 로 카드 삭제

서버 마이그레이션 035–045 를 순서대로 적용한 뒤 새 클라이언트를 서빙해야 합니다. 037 의
회차 전송(`occurrence_sync_enabled`)은 기본 비활성입니다. 회차 충돌의 자동 해결은 아직
지원하지 않으며, 겹친 회차는 양쪽 캘린더를 직접 확인해야 합니다. 실제 Google 계정과 다중
기기 운영 검증, 마이그레이션의 운영 적용은 이번 작업에서 수행하지 않았습니다.
