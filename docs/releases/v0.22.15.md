# FocusFlow v0.22.15

Google 전용 캘린더와 작업의 양방향 동기화 경로를 추가했습니다. 제목·설명·날짜·시간을
동기화하고, 양쪽에서 동시에 수정한 내용은 검토 화면에서 선택할 때까지 보존합니다.

- 일정 생성·수정·삭제, Google 삭제 시 작업 휴지통 이동, 복원 및 중복 가져오기 검토
- 여러 기기의 Task revision 검사와 응답 유실 후 중복 쓰기 방지·조회 복구
- 앱 반복 일정 생성, 명시적 반복 규칙 적용, 다른 연결 작업의 선택 복사
- 해결된 비교 기록의 30일 정리와 재시도 식별 정보 보존

새 동기화는 기본 비활성입니다. 서버 마이그레이션 021–034, 기존 연결 검증과 프로토콜
전환을 마친 계정부터 활성화해야 합니다. 실제 Google 계정·다중 기기 운영 검증 및
마이그레이션 적용은 이번 로컬 작업에서 수행하지 않았습니다. 비접속 계정의 기록 정리는
운영 환경에서 일일 작업 등록을 확인해야 합니다.

운영 절차: [Google Task rollout](../google-task-rollout.md)

로컬 검증: 테스트 3,244개 통과(기존 1개 건너뜀), production build 및 모바일 검토 화면 검사 통과.
플랫폼 설치 파일은 GitHub Actions의 CI와 Windows/macOS 빌드를 통과한 뒤 제공됩니다.
