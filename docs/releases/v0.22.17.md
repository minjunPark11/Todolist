# FocusFlow v0.22.17

집중 화면을 다시 지었습니다. 타이머·포모도로·기록이 같은 높이의 탭 셋이 되고,
타이머 화면에는 시계 하나만 남습니다.

- 타이머 · 포모도로 · 기록을 한 줄의 탭으로. 세션이 도는 동안 측정 방식은 잠기고, 왜
  잠겼는지 화면이 말합니다
- 작업 이름을 시계 위 한 줄(앵커)로 모으고, 시계를 얇고 크게(140px)
- 주 버튼은 언제나 하나. `세션 종료`는 빨강을 벗었습니다 — 집중을 끝내는 것은 완료이지
  파괴가 아닙니다
- 세션이 끝나도 화면이 바뀌지 않습니다. 같은 자리의 값만 바뀝니다
- 휴식은 포모도로 탭의 한 상태입니다. 라벨과 진행 막대의 값만 바뀝니다
- 작업 큐는 머리글의 `작업 큐`가 여는 대화상자로. 요약은 기록 탭으로, 메모는 원래의
  다이얼로그 경로로 돌아갔습니다
- 기록: 기간 칩(오늘·이번 주·이번 달·전체)과 날짜 이동이 한 줄에. 집중 시간·완료 세션·
  평균·가장 긴 집중과, 하루 24시간 위의 타임라인, 작업별 집중 시간, 최근 4주 패턴과
  7일 추이

접근성 결함 셋을 함께 고쳤습니다. 몰입 모드의 시계가 라이트 테마에서 대비 1.09로
사실상 보이지 않던 것, 다크 테마의 주 버튼이 3.65로 AA에 미달하던 것, 기록 화면이
가운데 정렬이라 머리글과 왼쪽 선이 어긋나던 것입니다. 셋 다 회귀 검사를 함께 두었습니다.

좁은 폭(1024 미만)의 배치는 CSS로 준비했지만 이번 작업에서 태블릿·모바일 뷰포트로
실행 검증하지는 않았습니다.

설계: [타이머·포모도로·기록](../../FOCUS_TABS_AND_RECORD_DESIGN.md)

로컬 검증: 테스트 3,569개 통과(기존 1개 건너뜀), typecheck·production build 통과,
영향권 E2E 43개 통과. 플랫폼 설치 파일은 GitHub Actions의 CI와 Windows/macOS 빌드를
통과한 뒤 제공됩니다.
